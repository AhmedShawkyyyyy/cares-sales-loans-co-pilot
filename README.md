# Car Sales Specialist Co-Pilot — حاسبة تمويل السيارات

تطبيق ويب داخلي لأخصائيي مبيعات السيارات لحساب تمويل السيارات فورياً: القسط الشهري،
المصاريف الإدارية، التأمين، وإجمالي المطلوب كاش عند الاستلام، مع ملخص عرض
جاهز للنسخ والمشاركة على واتساب.

## التقنيات

- **Angular 21** — Standalone Components + Signals + OnPush.
- **Tailwind CSS 4** عبر PostCSS.
- **TypeScript** في الوضع الصارم (`strict`).
- **RTL كامل** (`<html lang="ar" dir="rtl">`) وخط **IBM Plex Sans Arabic**
  من Google Fonts، مع أرقام جدولية للقيم المالية.
- **Vitest** لاختبارات الوحدة.

> Angular 21 هي أحدث نسخة متوافقة مع Node.js 22.16 المتاح في بيئة التطوير.
> للانتقال إلى Angular 22 يلزم Node.js 22.22.3 أو أحدث.

## قواعد الحساب

- `مبلغ التمويل = سعر السيارة − المقدم`
- `إجمالي الفوائد = مبلغ التمويل × (الفائدة السنوية ÷ 100) × عدد السنوات`
- `إجمالي المسدد = مبلغ التمويل + إجمالي الفوائد`
- `القسط الشهري = إجمالي المسدد ÷ (عدد السنوات × 12)`
- `المصاريف الإدارية = مبلغ التمويل × (نسبة المصاريف ÷ 100)`
- `مصاريف التأمين = سعر السيارة × (نسبة التأمين ÷ 100)`
- `المطلوب كاش عند الاستلام = المقدم + المصاريف الإدارية + مصاريف التأمين`

### فئات المقدم

| الفئة   | النطاق             |
| ------- | ------------------ |
| فئة 25% | 25% إلى أقل من 35% |
| فئة 35% | 35% إلى أقل من 40% |
| فئة 40% | 40% إلى أقل من 50% |
| فئة 50% | 50% أو أكثر        |

المقدم أقل من 25% يُظهر تنبيه «الحد الأدنى للمقدم هو 25%» ويُعرض الحساب
كتقدير مرجعي على سياسة فئة 25%.

### الفائدة والمصاريف

- **ملاكي + تنمية الصادرات (E-Bank):** سعر الفائدة تلقائي من جدول الفئات
  والمدة ونوع العميل، مع إمكانية تعديله يدوياً واستعادة سعر الجدول بزر
  «استعادة الافتراضي».
- **باقي البنوك أو السيارات التجارية:** سعر الفائدة إدخال يدوي إلزامي.
- **المصاريف الإدارية والتأمين:** تُعبّأ تلقائياً حسب البنك ونوع السيارة
  وفئة المقدم، وتبقى قابلة للتعديل مع شارة «مُعدّل يدوياً» وزر
  «استعادة الافتراضي».
